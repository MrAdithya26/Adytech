# SOP – publishing checklist (tick every box before going live)

## Before upload
- [ ] Fact-check sheet complete, no ⚠️ or ❌ left
- [ ] Level said in the video and shown on the thumbnail
- [ ] No personal or office data visible in any frame (pause through the whole video)
- [ ] Audio: no clipping, no fan noise, level consistent
- [ ] Every tool and repo credited on screen or in the description
- [ ] Commands in the description match the commands shown on screen, character for character

## YouTube
- [ ] Title from the three options; under ~60 characters
- [ ] Thumbnail readable at 25% size
- [ ] Description from template, with chapters, post links, credits, disclosure if needed
- [ ] Upload settings: category, language, captions, altered-content and paid-promotion boxes
- [ ] Added to the series playlist; end screen and cards set
- [ ] Scheduled for the slot (Sat 7:00 pm IST long; Mon/Wed/Fri Shorts)
- [ ] Pinned comment: commands or the post link

## AIH posts (Sunday)
- [ ] English and Telugu posts in Tech & AI → sub-category, level tag
- [ ] Video embedded, posts linked to each other
- [ ] "Checked on" date, sources and credits section
- [ ] Rank Math focus keyword and meta description filled

## After publishing
- [ ] Share in WhatsApp channel and Telegram (aih-social-distribution skill)
- [ ] Row updated in `tracker/content-tracker.csv` (and the Drive tracker when it exists)
- [ ] After 48 hours: note CTR and average view duration in the tracker
