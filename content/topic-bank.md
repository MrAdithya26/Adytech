# Adytech – topic bank v1 (31 Oct 2026)

72 topics: 4 pillars × 3 levels × 6 topics. ID format: `PILLAR-LEVEL-NN` (PC, MOB, NET, AI · B, I, A).

**Before scripting any topic:** check the current version, price and steps on a real device on the day of writing, and again on the recording day. Repo links below were confirmed to exist on 31 Oct 2026; features and install steps must be checked from each repo's README on the day.

Status: `idea` → `scripted` → `recorded` → `published`. Track status in `tracker/content-tracker.csv`, not here.
