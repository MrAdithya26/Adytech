# Episodes

One folder per long video: `episodes/<publish-date YYYY-MM-DD>-<topic-id>/`, for example `episodes/2026-12-12-AI-B-01/`.

Inside each folder (copied from `templates/`):
| File | From template |
| --- | --- |
| `script.md` | long-video-script.md |
| `shorts.md` | short-script.md (three Shorts) |
| `metadata.md` | youtube-metadata.md (3 title options, description, tags) |
| `thumbnail.md` | thumbnail-brief.md (+ Canva link) |
| `post-en.md` | blog-english.md |
| `post-te.md` | blog-telugu.md |
| `factcheck.md` | fact-check.md |
| `handson.md` | hands-on-guide.md (Intermediate and Advanced only) |

Video files, raw recordings and thumbnail PNGs go to Google Drive (06 Tech and AI Services › Adytech episodes › same folder name), not GitHub.
