# Apps and tools

Any app, script, extension or tool built for Adytech goes here, one folder each: `apps/<app-name>/`.

Each app folder has:
- `README.md` – what it does, level (Basic/Intermediate/Advanced), how to install and run (copy-paste commands)
- `VERSION` – the app's own version (`v1.0.0`, `v1.1.0` …)
- `CHANGELOG.md` – the app's own change history
