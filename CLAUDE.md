# CLAUDE.md – rules for working on Adytech

## Who and what
- Owner: Adithya (Srikakulam, Andhra Pradesh). Part of ABD Innovations (Adithya Business and Digital Innovations).
- Adytech (working name; public name pending, Adygeek proposed) = tech content in Telugu: YouTube + adithyainfohub.com/tech-ai/.
- Pillars: PC · Mobile · Internet and online safety · AI. Levels: Basic · Intermediate · Advanced.
- The team does not code. Explain everything in plain English a beginner can follow.

## Content rules
1. Check current versions, prices and features on the web before stating them; flag anything that may be out of date; write "Checked on <date>".
2. Mark the level on every piece.
3. Credit every GitHub repo and tool with its real name and link. Never invent features; only claim what the repo's README, the official docs or a real test shows.
4. Give copy-paste-ready text, code and commands in code blocks.
5. Narration and Telugu posts: Telugu first, English only for words hard in pure Telugu; menu names and commands exactly as on screen.
6. No piracy, cracks, modded APKs, hacking or paywall bypasses. Security topics are defensive only.
7. Disclose affiliate and paid links. Nothing from Adithya's office work or election data appears anywhere.
8. Own screenshots and recordings only.

## Owner's standing rules (apply to the whole ABD ecosystem)
1. Never delete anything without Adithya's permission. GitHub: only new commits; no force-push, reset, rebase or deleted files. Drive/Docs: never delete; updates are new dated copies. Sheets: never clear or overwrite; add rows or a dated tab.
2. Log every change in `CHANGELOG.md`: date, what it was before, what it is now, what was removed (and where the old copy is), why.
3. Every update, plan and decision goes to BOTH GitHub and Google Drive (ABD INNOVATIONS › 06 Tech and AI Services), and a status line goes to `MrAdithya26/ABD-Innovations › projects/ADYTECH.md`.
4. Tell Adithya about every change, however small.
