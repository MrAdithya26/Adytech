# Fact-check sheet – template

One per episode, saved as `episodes/<folder>/factcheck.md`. Every claim with a number, version, price, limit, date or feature gets a row.

| # | Claim in script / post | Source (official page, release notes, or own test) | Checked on | Result |
| --- | --- | --- | --- | --- |
| 1 | | | | ✅ matches / ⚠️ changed / ❌ wrong |

**Rules**
1. Official sources first: the tool's own site, docs, release notes, GitHub README and Releases page, government portals.
2. "Own test" counts only if done on a real device that day; write the device and version.
3. A ⚠️ or ❌ row is fixed in the script before recording.
4. If something may change soon (price, free tier, beta feature), the video says "as of <month year>" and the post shows "Checked on".
5. Never cite a forum, another YouTuber or an AI answer as the source.
